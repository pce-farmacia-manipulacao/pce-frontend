# PCE - Frontend Application

Esta é a interface de usuário (UI) da aplicação web para clientes de farmácia de manipulação, desenvolvida de forma responsiva utilizando React.js e estilizada para garantir portabilidade e usabilidade.

## 🚀 Status do Desenvolvimento
O repositório está configurado e preparado para receber os componentes modulares em React, incluindo as telas de:
* Login seguro e autenticação.
* Painel do cliente com histórico de compras.
* Fluxo simplificado para repetição de pedidos validados.

A comunicação com o ecossistema do backend será realizada de forma assíncrona através do cliente HTTP Axios.
